ELI5 · anthropics/commerce-agents

一个店员，一个循环

这个仓库里的「购物 agent」就是一个店员。它每次只做一件事：听客人说一句，想一下，去查，再把商品摆给客人看。然后等下一句。下面七张图讲它为什么这样转。

01 · 一转

客人每说一句话，店员就转一圈

整个系统只有这一个圈。没有前台分流，没有第二个店员。

术语钉住

「工具」= 店员能喊的每一句「帮我查 X」。「gate」= 保安。「tool result」= 货架送回来的纸条。

02 · 为什么只有一个店员

换人就得重讲一遍篮子里有什么

很多人第一反应是搜索一个店员、售后一个店员、结账一个店员。这个仓库反着来。

规则只有一条：接手的人需不需要篮子？需要，就别换人。

03 · 店员随身带的三样东西

每次都看的挂胸前，偶尔看的放抽屉，每次都变的写手背

店员每转一圈都要重新读一遍自己带的东西。放的位置决定了读得快不快。

术语钉住

胸牌 = system prompt。抽屉手册 = skills。手背便签 = 每次请求的上下文。「读过就跳过」= prompt caching。

04 · 钱

店员的工具箱里没有收银机

不是叮嘱它「别乱收钱」。是它根本没有那个按钮。

术语钉住

便签 = staged change。老板签字 = host approval。本店签发的编号 = provenance。

05 · 记住客人

下班后有个秘书整理笔记，只听人说的话

店员在接客的时候不停下来记笔记。记笔记是另一个人的活。

06 · 考试

不考整场对话，摆好一个场景问一句

怎么知道店员靠不靠谱？不是找人陪它聊一小时。

07 · 合起来

它为什么这样工作

一个店员在场 → 篮子不用重讲。
规矩按用得多不多分三层 → 读得快。
没有收银机、只认本店编号 → 出错也只是说错话，不是做错事。
店员管想，代码管做。

这份解释故意省掉了三样东西。

  • 那个唯一的「第二个人」。商家店员有一个只读的分析助理，能查报表、不能写任何东西。它是仓库里唯一被允许的「换人」，看它怎么被关进笼子：commerce_common/delegation.py，59 行。
  • 「读过就跳过」的三个断点具体放哪。在 commerce_common/prompt_assembly.py，119 行。
  • 考题长什么样。仓库不带考卷，只给了题目的格式：插件里的 commerce-evals/SKILL.md。

全部 20 条「保安规则」各在哪个文件，一张表：docs/safety.md，86 行。
